# kagent.api.v1alpha1 client stubs

Go stubs of the kagent gRPC services klaus-gateway calls: `AgentService`, `SessionService`,
`AgentTemplateService`, `ModelService` and `HarnessService` (plus `common` and `runtime`).
Generated by `buf` (protoc-gen-go v1.36.12, protoc-gen-go-grpc v1.6.0) from the protos under
`hack/kagent-proto/`, which are verbatim copies of `proto/kagent/api/v1alpha1/` in
`giantswarm/kagent-upstream` at the commit below; `buf.lock` pins the `buf/validate` dependency
to the same commit's lock. The A2A v1 service (`lf.a2a.v1.A2AService`) is not generated here:
klaus-gateway uses the stubs `github.com/a2aproject/a2a-go/v2/a2apb/v1` ships.

Do not edit the generated files. To move the pin, set `KAGENT_PROTO_COMMIT` in
`Makefile.custom.mk` and run `make generate-kagent` (needs `buf`, `protoc-gen-go` and
`protoc-gen-go-grpc` on the PATH); the target runs `goimports` over the output because the
repository's CI formats every Go file with it.
